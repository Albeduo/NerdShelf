# Semana 01 — Fundação

**Fase:** Fundação (Semanas 1–2)
**Período:** – 2026-08-20

## O que eu construí?
- `README.md`, `ROADMAP.md` e `LICENSE` definindo objetivo, eixos de aprendizado, stack inicial e identidade visual do projeto.
- `CONTRIBUTING.md` documentando o fluxo de trabalho (Issues, branches, Pull Requests, Conventional Commits) mesmo sendo um projeto solo.
- Estrutura `docs/` com o processo de Weekly Review.
- Estrutura `.github/` com templates de Issue (tarefa semanal, bug, feature) e de Pull Request.
- `.gitignore` mínimo, agnóstico de stack.

## O que eu aprendi?
- Como estruturar a documentação de um projeto open source desde o início (README, ROADMAP, CONTRIBUTING, templates de Issue/PR).
- A diferença entre planejar processo (Semana 01) e planejar ambiente técnico (Semana 02).
- Fluxo básico de Git/GitHub: convenção de commits, Issues, Pull Requests — mesmo antes de existir código.
