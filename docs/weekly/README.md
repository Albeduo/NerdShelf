# Weekly Reviews

Ao final de cada semana do `ROADMAP.md`, criar um arquivo `week-XX.md` (dois dígitos, ex: `week-01.md`, `week-02.md`) respondendo:

1. O que eu construí?
2. O que eu aprendi?
3. O que deu errado?
4. O que eu faria diferente?
5. Qual será meu próximo passo?

## Template

```markdown
# Semana XX — <Fase>

**Fase:** <nome da fase, conforme ROADMAP.md>
**Período:** <data de início> – <data de fim>

-

-

-
```
