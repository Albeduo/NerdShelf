# NerdShelf

NerdShelf é uma plataforma de **gestão de coleções Geek**, criada com o propósito de **aprender engenharia de software enquanto constrói**.

## 🎯 Objetivo

Transformar o aprendizado em prática real, desenvolvendo um sistema completo para organizar coleções de:

- TCGs (Magic, Pokémon, Yu-Gi-Oh!, Flesh and Blood, Lorcana, Riftbound)
- Colecionáveis (Funko, Gundam)

O projeto segue a filosofia **Build-to-Learn** — aprender arquitetura, código e boas práticas através da construção de um produto real.

## 🧩 Stack inicial

| Camada | Tecnologia |
|--------|-------------|
| Frontend | Next.js + React + TypeScript + Tailwind + shadcn/ui |
| Backend | NestJS + TypeScript + Prisma |
| Banco | PostgreSQL |
| Testes | Vitest + Playwright |
| Infra | Docker + GitHub Actions |
